# AWS Interview Preparation

AWS interview questions for MERN / Node.js developers, organized from fundamentals to production scenarios.

## Topics
- AWS fundamentals and IAM
- EC2, AMI, EBS and launch templates
- S3 and CloudFront
- VPC and networking
- Load balancing and Auto Scaling
- RDS and DynamoDB
- Lambda and API Gateway
- Route 53, CloudWatch and CloudTrail
- SQS and SNS
- ECS, ECR, EKS and Docker
- CI/CD and deployments
- Security and secrets management
- Production architecture scenarios

## Study approach
Start with [AWS Interview Questions](QUESTIONS.md). Practice explaining each answer in this order:
1. Short definition in English
2. Explanation in simple Hinglish
3. Practical example
4. Production/interview scenario

Questions are a study roadmap, not a guarantee of what any interviewer will ask.
